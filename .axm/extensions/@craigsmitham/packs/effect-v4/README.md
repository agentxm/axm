# Effect v4

This pack installs version-matched guidance for Effect 4.0.0-rc.110:

- `craft-effect-v4` routes TypeScript architecture, implementation, and review
  work to the smallest relevant guide.
- `effect-v4` provides twenty opinionated guides covering data modeling,
  services, failure, lifetimes, concurrency, platforms, and verification.

Install the pack for the complete routing and reference pair.
