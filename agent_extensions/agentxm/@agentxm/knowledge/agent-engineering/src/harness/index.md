# Harness

The system around the agent that implements the loop and supplies runtime,
tools, state, feedback, and enforcement.

- [Harness engineering](harness-engineering.md) - How runtime, interfaces,
  state, feedback, authority, and environment adaptation turn model capability
  into reliable agent behavior.
- [Harness classification](harness-classification.md) - Independent
  implementation axes and applied profiles, without absorbing agent behavior or
  product labels.
- [Runtime and environments](runtime-and-environments.md) - Runtime substrates,
  adapted working environments, execution, isolation, reproducibility, and
  topology.
- [Action and observation interfaces](action-and-observation-interfaces.md) -
  Exposing useful capabilities and legible environmental state, and rendering
  questions and choices to a person.
- [State and continuity](state-and-continuity.md) - Preserving task and
  execution state across long work, retries, interruption, and handoff.
- [Feedback and verification](feedback-and-verification.md) - Turning action
  consequences into useful feedback and establishing completion with evidence.
- [Authority and containment](authority-and-containment.md) - Granting useful
  capability while structurally limiting effects and escalation.

For measuring a harness, see
[evaluating and improving harnesses](../evaluation/evaluating-and-improving-harnesses.md).
