# Synthetic evidence package for admission

A skill submitted for admission ships an evidence bundle with three claims.

**Routing.** The description was rewritten five times against a twenty-case
routing set until nineteen of twenty passed, and 95% is reported as the routing
result. The twenty cases are the only ones that exist. Each case was run once.

**Comparison.** A model judge picked the better of two outputs across eight
cases and chose this skill's output every time. The judging prompt stated which
output came from the skill under review. The bundle reports "8/8 preferred" as
evidence of improvement.

**Execution.** Six assertions pass on all six with-skill trials and on all six
without-skill trials. The bundle reports a 100% pass rate as evidence that the
skill works.

Target identity, harness, host, model, and raw transcripts are all present and
clean. The submitter asks for an admission decision.
