# Requirements engineering knowledge

Portable guidance for requirements elicitation, analysis, specification,
review, traceability, lifecycle, and evidence across project methods and tools.

Install the supported pack rather than this non-standalone member:

```sh
axm packs install @craigsmitham/packs/requirements-engineering
```

Start with the [portable requirements engineering model](src/foundations/portable-requirements-engineering.md).
Projects retain authority over their domain vocabulary, approval model,
requirement hosts, and additional content obligations.

The knowledge package is licensed under CC-BY-SA-4.0 and is maintained as an
independent, method-neutral requirements-engineering reference.
