DESCRIPTION
     Install extensions from a Registry, Git, or path source

USAGE
     axm install [flags] <source>

ARGUMENTS
     <source>                      Registry FQN (@owner/<plural-type>/<name>[@version]), self-describing Git locator, or path locator (required)

FLAGS
     --scope                       Workspace scope (choices: project, user; default project)
     --all                         Install every matching extension without prompting
     --ignore-release-age          Take a release younger than the configured minimum release age, for this run only

GLOBAL FLAGS
     --json, -j                    Output machine-readable JSON
     --directory, -C               Run as if AXM was started in this directory (relative paths resolve from there)

EXAMPLES
     # Install a skill by registry FQN
     axm install @acme/skills/code-review

     # Install every extension from a Git source
     axm install --all github:acme/agent-extensions

LEARN MORE
     axm help basic-usage          Managing extensions and agents for an AXM workspace
     axm help skills               How skill extensions work
