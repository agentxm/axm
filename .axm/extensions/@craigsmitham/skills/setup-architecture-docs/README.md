# Set up architecture docs

Establishes the minimal repository-local adoption, navigation, authority, and
agent discovery needed to use Just Enough Architecture Docs without generating
an empty documentation tree or substantive architecture by inference.

Use it when a repository is adopting the practice for the first time or needs
an existing architecture-doc location connected to the software-architecture
pack. Do not use it to choose an architecture, author substantive desired-state
meaning, or maintain established architecture docs.

This skill is a non-standalone member of the software-architecture pack because
it loads that pack's software-architecture knowledge.

## Install

```bash
axm install @craigsmitham/packs/software-architecture
```

## Example

> Set up Just Enough Architecture Docs for this repository. Preserve the
> existing `docs/architecture/` material, avoid empty collections, and surface
> missing lifecycle or stewardship context for later authoring.
