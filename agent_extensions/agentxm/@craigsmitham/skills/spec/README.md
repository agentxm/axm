# Spec

Produces one Change Specification for why and what must change. When a Pitch
exists, `$spec` accepts only its exact persisted Ready revision before work.
The first coherent Specification Draft and later state changes are persisted
in one canonical Change target.

Spec owns semantic Requirement, Architecture, and Evaluation Protocol changes,
not Design, executable tests, delivery, or release. Artifact acceptance remains
separate from human authority over governed meaning. Its compact portable form
puts Summary and Open items first, then records governed changes as scannable
identity-bound cards with authority beside each disposition.

Install it through `@craigsmitham/packs/gen-stack`; it is not standalone.
