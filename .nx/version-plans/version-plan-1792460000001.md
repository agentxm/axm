`@agentxm/extension-model/unstable/path-types` no longer exports `isWithinOrEqual` or `isStrictlyWithin`. Native agent configuration files are read through one JSON, JSONC, YAML and TOML grammar, so an empty file or a comment-only YAML document reads as an empty configuration on every path, and removing or retiring an MCP server entry honours the target agent's declared JSON or JSONC strictness.
