# Synthetic AXM-managed instruction system

The project contains `axm.json` with instruction-file management
enabled and `AGENTS.md` as the canonical source. AXM reports:

- `AGENTS.md` as the current canonical source for Codex and Cursor;
- `CLAUDE.md` as an AXM-owned copied projection that is missing the latest
  canonical invariant;
- an AXM-owned Rules region inside `AGENTS.md` that is current; and
- an AXM-owned Knowledge discovery region inside `AGENTS.md` that is current.

Current AXM instruction help, `axm instructions`, `axm lint`, and read-only
reconciliation preview are available. The audit is read-only. Do not apply
sync, edit the canonical source, repair the projection, or change either
contributed region.
