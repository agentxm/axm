# Skills

Skill packages live in `./.axm/extensions/<@owner>/skills/<skill-name>`.

- `skill.json` is the package manifest for the agentxm.ai registry.
- `src/` contains `SKILL.md` and any other files from the agentskills.io
  specification.

## Where to go next

- `axm skills --help` — full skill subcommand surface.
