Store the workspace lockfile as TOML in `axm.lock` (lockfile version 1) instead of YAML in `axm-lock.yaml` (version 12), in project and user scope. Each retained package is one `[[package]]` record whose `id` is its directory under `agent_extensions/`, each selected extension is one binding line with its declared `name`, MCP selections are `[[mcp]]` rows, projection currency moves to `[projections.<kind>]` tables, and other tools may keep data under `[tool.<name>]`, which AXM preserves and never reads. AXM rewrites the whole file canonically, so the same state produces the same bytes on every machine, and comments or hand edits do not survive the next write. Nothing is migrated: a workspace that still has `axm-lock.yaml` is refused as an older lockfile, even beside an `axm.lock`, until you back the file up outside the workspace, remove it, review `axm sync --preview`, and run `axm sync`. External resolutions may advance, and because the old projection records are not read, replacing a differing whole file needs `--replace-unrecorded` once. Lockfile syntax errors now name TOML.
