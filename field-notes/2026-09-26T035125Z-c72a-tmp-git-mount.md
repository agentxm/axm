# Mounted /tmp/.git changes the Git-workspace fixture result

## Context

The instruction projection suite creates temporary workspaces under `/tmp` and has two cases asserting behavior outside a Git workspace.

## Friction

An empty `/tmp/.git` directory was present while the suite ran. Both outside-Git cases observed their temporary workspaces as Git-managed and reported `.gitignore` writes. Attempting to remove the empty directory with `rmdir /tmp/.git` failed with `Device or resource busy`.

## Cost / impact

Two of 43 existing instruction tests failed for this environment condition. A focused new preview/apply parity case passed. The failed cases could not be rerun with `/tmp/.git` absent in this VM.

## Outcome

The directory remained untouched after `rmdir` failed. Work continued with the two test failures recorded as an environment limit.

## Evidence

`pnpm exec nx run workspace:test --excludeTaskDependencies --args="src/projection/instructions/instructions.test.ts --reporter=json --outputFile=/tmp/axm-work-step49-instructions.json"` reported 41 passed and 2 failed. `ls -la /tmp/.git` showed an empty directory; `rmdir` returned `Device or resource busy`.
