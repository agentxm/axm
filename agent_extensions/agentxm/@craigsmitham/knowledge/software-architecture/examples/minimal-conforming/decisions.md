# Architecture decision policy

Repository review accepts and may supersede architecture decisions for this
synthetic reference. Record an ADR when a durable choice among meaningful
alternatives materially constrains the example and its consequences would be
difficult to recover from the remaining concepts. Each record must state its
context, accepted choice, rationale, consequences, and reconsideration or
supersession conditions.

No local ADR is currently justified: the fixture contains no accepted choice
whose reasoning needs an independent lifecycle. Reassess that conclusion when
a future profile example introduces such a choice. Until then, repository
review remains the alternative decision authority and no `decisions/`
collection is maintained.
