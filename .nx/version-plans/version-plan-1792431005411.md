Name every extension type's manifest file from the extension type table, so the manifest filename, default authored directory and type order are declared once. `axm <type> new` now refuses a name that the extension name grammar rejects, such as one ending in a hyphen, with a validation error for every type instead of an internal error. Paths inside a directory whose name starts with two dots, such as `..cache`, now count as contained. Registry and `axm view` visibility fields share the canonical extension visibility schema, and the machine-output JSON Schema references it.
