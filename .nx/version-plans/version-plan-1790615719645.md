Report CLI failures as a bounded, privacy-preserving telemetry report with an inspectable preview mode. An opted-in invocation sends at most one error report, carrying only an allowlisted failure kind, category, class, and handled flag, the time it occurred, the phase, command name, client facts, and random correlation IDs, never messages, stack traces, arguments, paths, or environment values. `AXM_TELEMETRY_PREVIEW=1` prints each would-be telemetry payload to stderr and sends nothing.
