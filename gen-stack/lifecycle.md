# AXM lifecycle

## Accepted lifecycle state

AXM is in early-alpha, pre-launch active development. Capabilities, contracts,
and APIs may change as the System converges on public-launch scope.

The canonical
[pre-launch contract-change Requirement](/system/requirements/process/pre-launch-contract-changes-remain-coherent.md)
owns the binding obligation for clean pre-launch change.

## Change horizon and expected evolution

Near-term change may be frequent and structurally significant. AXM is expected
to continue active development toward public launch without preserving
superseded compatibility-only paths.

Current schedules, delivery state, and release state remain with GitHub and the
repository's release workflow rather than this concept.

## Reassessment triggers

Reassess this lifecycle when AXM reaches public launch, accepts an external
support or compatibility commitment, materially changes its System boundary or
operating model, or enters replacement, retirement, or sustained maintenance.
