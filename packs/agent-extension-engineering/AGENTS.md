# Engineering pack maintenance

Before changing this package, read the
[Agent extension enablement architecture](../../docs/architecture/extension-enablement.md).
It owns the collection's responsibility, optionality, and composition boundary.

When a change affects how the members work together, start with a task the
pack README promises. Follow it through the installed skill to the concept
supplied by the knowledge bundle. Check what the consumer can decide or do
with the result using the members the pack declares.

This file is repository maintainer guidance. Keep it excluded from publication.

Use the [Agent Extension Glossary](../../knowledge/agent-extension-engineering/src/glossary.md)
for shared meanings. Keep definitions in that knowledge concept and maintain
consistent terminology in documentation, help, skills, and product copy.
