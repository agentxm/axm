`@agentxm/workspace-conventions` no longer ships the staged commit gate: `bin/check-staged.mjs`, its Bash gate and lint-staged configuration, and the `lint-staged` peer dependency are removed. The package now provides only the capability-boundaries ESLint preset. Repositories that started the gate from a pre-commit hook can run their formatter followed by `axm lint --staged`, as `axm help git-hooks` describes, and keep full verification in pre-push or CI.
