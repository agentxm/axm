# Context engineering knowledge

Portable knowledge for shaping the informational environment an agent receives,
discovers, produces, and carries through work. Use it for context authority,
selection, routing, retrieval, instructions, memory, feedback, compaction, and
maintenance; use prompt engineering for intentional instruction content and
agent engineering for behavioral policy, and harness engineering for runtime,
persistence, interfaces, and structural control.

## Begin with the context system

- [Context engineering foundations](foundations/) - The context lifecycle, forms, quality,
  authority, and boundaries from neighboring disciplines.

## Design selection and discovery

- [Context design](design/) - Progressive disclosure and persistent instruction
  surfaces that keep context relevant and discoverable.

## Operate across time

- [Context operations](operations/) - Context gardening, evaluation, memory,
  compaction, feedback, and continuity.

## Apply to software engineering

- [Software-engineering context](domains/software-engineering/) - Repository
  instructions, environment routes, and specification-authority patterns.
