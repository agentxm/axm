# Supporting quality criteria

Checklists for subjects that can support product-quality claims but are not
the software product itself. Give each supporting subject its own assessment;
never substitute that verdict for an applicable [product-quality
criterion](../criteria/) or treat artifact presence as assurance.

- [Test-suite quality criteria](test-suite-quality.md) - Use when assessing automated tests as supporting artifacts; evaluate whether the suite provides valuable, sustainable, and appropriately bounded evidence for applicable product-quality claims.
