New package `@agentxm/workspace-conventions` publishes engineering conventions for Nx and pnpm TypeScript workspaces, starting with `capabilityBoundaries` from `@agentxm/workspace-conventions/capability-boundaries`: an ESLint flat-config preset built on `eslint-plugin-boundaries` that keeps capability dependencies flowing through public domain and application entries, keeps capability code inside its domain, application, adapters and composition folders, and keeps filesystem, provider and ambient process access out of domain and application code. Workspaces extend it through ordered options (`additionalAllows`, `additionalDenials`, `policyExternalModules`, `policyRestrictedImports`, `testAccess`, `placementFiles` and `resolverConditions`) so that an added allowance never overrides a shared denial. The package is engineering support, unstable, and outside the AXM runtime.
