Adopt Registry API 0.2.0. Owner and type listings follow Registry cursor pages to the end. Registry problem codes reported in `metadata.response.problemCode` are now snake_case (for example `publish_quota_exceeded`, `publish_precondition_changed`), and token, identity, extension and publish responses are read with camelCase fields. Requires the Registry API 0.2.0 contract. The CLI now targets Telemetry Ingest API 0.6.0.
