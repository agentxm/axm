# Extension Type Icons

This folder contains one icon per extension type in `packages/cli/src/extensions/common.ts`.

- `skill`
- `command`
- `pack`
- `mcp-server`

Source priority:

- SVGL (https://svgl.app/) when a canonical logo exists (currently `mcp-server`)
- Generated monogram SVG for generic extension types

## Files

- `<extension-type>.svg`: icon asset for that extension type
- `sources.json`: source metadata for each icon
