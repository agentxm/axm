# Behavioral evaluation cases

The machine-readable authority is `evals.json`. Run each case in a fresh,
disposable context with the Gen Stack knowledge support path. The suite covers
positive routing, one adjacent collision, stage-specific happy and boundary
execution, Pitch handoff, human-ratifiable Architecture completeness, semantic
Protocol coverage, implementation-level Evaluation/test agnosticism, and
forbidden side effects. Missing side-effect evidence is
`unknown`, never an inferred pass.
