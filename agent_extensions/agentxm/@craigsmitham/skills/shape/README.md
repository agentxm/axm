# Shape

Shapes a raw or mixed change into one bounded, repository-grounded Pitch.
The first coherent Draft is persisted immediately; ordinary chat iteration is
not synchronized; state changes update the same canonical artifact in place.

Select `$shape` explicitly. Shape uses the shared `Draft`, `Ready`, and
`Accepted` lifecycle and the shared first-screen identity, Summary, and Open
items order. It includes a filesystem or relationship sketch only when
topology materially helps. It does not accept
desired meaning, select Design, plan, prioritize, implement, or release.

Install it through `@craigsmitham/packs/gen-stack`; it is not standalone.
