- [Defects](defects/index.md) — Discrepancy evidence, disposition, correction, and report presentation.
- [Testing pattern collection](patterns/index.md) — Choose how to express an agreed rule, decide which components its check must exercise, or assign responsibility for a test that spans boundaries.

- [Foundations](foundations/index.md) — Explainers for software testing.
