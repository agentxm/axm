# Behavioral evaluation cases

Run each prompt in a fresh agent context with the skill and the
software-architecture knowledge bundle. Do not provide the expected output or
assertions to the test agent. `evals.json` is the machine-readable authority.

The cases cover minimal adoption, preservation of established local structure,
ambiguous system boundaries, resistance to empty taxonomies and invented
architecture, optional OKF adoption, and the boundary between setup and
maintenance. They also cover stable named identity from the first concept and
lifecycle or stewardship gaps that setup must surface without inventing.

The suite passes when setup leaves one discoverable architecture-doc root,
records only accepted local choices, preserves existing material, and defers
substantive authoring or maintenance to their owning workflows.
