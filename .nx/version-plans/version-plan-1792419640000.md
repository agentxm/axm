`@agentxm/extension-model`, `@agentxm/extension-content`, `@agentxm/registry-protocol` and `@agentxm/specification-metadata` now declare `effect` as a peer dependency (`^4.0.5`) instead of pinning an exact runtime dependency, so a consumer supplies the one Effect runtime its process loads. The `axm.sh` CLI keeps its exact Effect pin.
