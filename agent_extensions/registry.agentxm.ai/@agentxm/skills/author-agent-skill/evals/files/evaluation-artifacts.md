# Synthetic repository evaluation profile

The repository publishes only `skill-package/src/` as the runtime Agent Skill
payload. It stores reviewed evaluation source in `skill-package/evals/` and
ignores `.work/evals/` for generated runs.

Create a new `normalize-release-notes` skill from the coherent workflow
requirements supplied separately at `inputs/requirements.md`. Its behavior
should be protected by a clear routing positive, a paraphrase, an adjacent
deployment negative, and one activated execution case. The current authoring
session cannot provide isolated trials or independent review. No release
evidence exists.
