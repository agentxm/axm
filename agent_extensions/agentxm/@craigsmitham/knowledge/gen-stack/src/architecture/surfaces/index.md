# Surfaces

Guidance for actor-facing encounter points, independently from their C4
structural realization.

- [Developing Surfaces](developing-surfaces.md) - Use when greenfield intent or brownfield interaction evidence suggests a missing, underdeveloped, misplaced, or disputed actor-facing boundary; develop the smallest candidate Surface set without treating routes or current UI structure as accepted Architecture.
- [Documenting surfaces](documenting-surfaces.md) - Use when an accepted actor-facing encounter point needs canonical identity independent of its structural realization; record one Surface concept and its earned navigation.
