# Spec

Distills why and what must change into the canonical Change Specification for
one bounded Change. It preserves source provenance and authority, bounds outcomes
and scope, fully dispositions affected Requirements and Architecture, names
the exact Requirement-satisfaction and Architecture-realization Evaluation
Protocol changes, and reconciles design-first proposals without treating their
mechanism as accepted desired state.

When a shaped Pitch is supplied, Spec preserves it as provisional provenance
and determines the actual desired-state delta rather than copying anticipated
impact into accepted meaning.

Spec is agnostic about implementation-level Evaluations and tests. It defines
semantic Protocol claims and coverage needed for human sign-off, while Design
owns their technical realization and any optional Implementation-conformance
Evaluations.

When the Change is classified as Bugfix, Spec applies the same artifact
contract with conditional remediation content. Pitch-first,
specification-first, and design-first work converge with `design` at the Gen
Stack change-coherence gate. Install this non-standalone skill through
`@craigsmitham/packs/gen-stack`.
