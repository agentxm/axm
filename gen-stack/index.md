# AXM Gen Stack

This corpus governs accepted change meaning for the public AXM CLI and its
OSS-safe reusable core. It adopts the
[Gen Stack profile](https://github.com/agentxm/axm/blob/main/agent_extensions/agentxm/@craigsmitham/knowledge/gen-stack/src/profile/gen-stack-application-profile.md)
version 0.5.0.

Detailed implementation-responsive architecture remains in the
[AXM architecture corpus](https://github.com/agentxm/axm/blob/main/docs/architecture/index.md).
Code, schemas, configuration, tests, CI executions, and runtime observations
retain their repository-native authority.
