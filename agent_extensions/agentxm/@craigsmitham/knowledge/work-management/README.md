# Work management knowledge

Portable reference material for consistent software work items across
repositories and trackers. It defines Operational Incident Records, Defect
Reports, Changes, their shared content and lifecycle concerns, and compact
fallback templates.

Install the supported pack rather than this non-standalone member:

```sh
axm packs install @craigsmitham/packs/work-management
```

Start with [Software work-item taxonomy](src/software-work-item-taxonomy.md).
The bundle is tracker-neutral and delivery-method-neutral. Repository
instructions may add domain-specific content obligations, while native tracker
fields remain the preferred representation for facts they can carry exactly.

independent, method-neutral work-management reference.
