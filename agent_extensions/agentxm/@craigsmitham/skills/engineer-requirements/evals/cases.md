# Behavioral evaluation cases

Run each case in a fresh context. Do not expose expected outputs or assertions
to the trial agent. `evals.json` is the machine-readable authority.

Cases 1–7 exercise activated execution: implementation-derived candidates,
project-specific accepted requirements, unknown quantitative targets, bounded
set review, split lineage, read-only host mapping, and incomplete external
conformance requests.

Cases 8–12 exercise routing: positive candidate development, implementation and
test-execution negatives, a Work Management handoff, and an ambiguous cleanup
request that requires clarification or abstention.

The initial suite passes only when all critical gates and material assertions
pass in the declared environment. Authoring smoke is development evidence, not
independent evaluation or release approval.
