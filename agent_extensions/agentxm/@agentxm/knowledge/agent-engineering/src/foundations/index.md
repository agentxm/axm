# Foundations

What agent engineering covers, how the parts of an agent system fit together,
and how responsibility divides among them.

- [Agent engineering](agent-engineering.md) - The discipline as the design and
  stewardship of goal-directed model behavior.
- [Agents, workflows, and automation](agents-workflows-and-automation.md) -
  Model-directed agency distinguished from predefined execution and simpler
  automation.
- [Autonomy and risk classification](autonomy-and-risk-classification.md) -
  Classifying deployed agency by decision freedom, reach, duration,
  supervision, reversibility, and consequence.
- [Agent-system composition](agent-system-composition.md) - How agents,
  harnesses, environments, runtime substrates, orchestration, governance, and
  evaluation compose without becoming synonyms.
- [System elements and boundaries](system-elements-and-boundaries.md) - Which
  surface owns each concern, and how behavior, prompts, context, harness,
  skills, and evaluation divide responsibility.
- [Agent legibility](agent-legibility.md) - Making task-relevant intent, state,
  capabilities, constraints, and feedback discoverable and usable by an agent.
