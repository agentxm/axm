# Agent Icons

This folder contains one icon per supported agent ID in `packages/cli/src/agents`.

- Source priority: SVGL (https://svgl.app/) when a matching logo exists
- Fallback: generated monogram SVG for agents without a matching SVGL logo

## Files

- `<agent-id>.svg`: icon asset for that agent
- `sources.json`: source metadata for each icon

Brand logos and trademarks belong to their respective owners.
