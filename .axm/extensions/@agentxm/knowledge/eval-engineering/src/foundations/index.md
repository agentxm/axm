# Foundations

Core distinctions for deciding what an evaluation is, what it measures, and
which system administers it.

- [Evaluation engineering](evaluation-engineering.md) - Defines evaluation engineering as a cross-cutting assurance discipline tied to decisions and deployment context.
- [Evaluation boundaries](evaluation-boundaries.md) - Distinguishes evaluations from tests, verification, benchmarks, red teaming, monitoring, experiments, and audits.
- [Evaluation systems and harnesses](evaluation-systems-and-harnesses.md) - Separates the target, operational agent harness, evaluation harness, environment, evidence, and decision.
