`@agentxm/extension-content/knowledge` exports `resolveKnowledgeLink`, which resolves a link authored in a Knowledge document against the bundle's file paths with the same rule Knowledge inspection uses for `authoredLinks[].resolvedConceptId`. It reports a URL as `external`, a query or fragment alone as `same-document`, a path outside the bundle as `escaped`, a bundle path with no file as `missing`, and otherwise the resolved Markdown document with its concept ID or the resolved asset, keeping the link's query and fragment. Extensionless and directory links such as `guides` and `guides/` resolve to `guides.md` or `guides/index.md`, so renderers can rewrite links without their own copy of the rule.
