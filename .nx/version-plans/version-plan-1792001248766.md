Bind every Registry operation to one validated endpoint. A Registry `location` and `--registry` URL must be an http(s) origin or a `file:` URL without credentials, a query, a fragment, or (for http(s)) a path; equivalent spellings name one Registry and share its saved session. A default or named source that no settings configure, or settings that cannot be read, now fails with a typed `registry-source-unknown` problem or the settings diagnostic instead of falling back to the AgentXM Registry, and commands that never use a Registry no longer read the selection. `AXM_TOKEN`, `AXM_TOKEN_FILE`, and a GitHub Actions identity are presented only to the settings-selected default Registry: a pipeline that publishes to another Registry with `--registry` must make it the `defaultRegistry` or use a saved session. AXM refuses Registry and GitHub ID-token redirects, keeps credentials within their Registry origin, and refuses authentication, deprecation, yank, and archive against a file Registry with a `registry-operation-unsupported` problem before any request or change. Equal names from different Registries stay distinct, Pack show reports each member's declaration, source identity, and resolution status, and an absent Registry constraint admits exactly what `*` admits: a workspace holding an unconstrained prerelease is refused by sync until `axm update` selects an admitted version.
