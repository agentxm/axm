# Process Requirements

Durable obligations on how AXM is changed, reviewed, and assured.

- [Public artifacts protect private context](public-artifacts-protect-private-context.md) -
  Changes keep private coordination, customer, and confidential material out of
  the public AXM repository.
- [Changes land through pull requests](changes-land-through-pull-requests.md) -
  AXM changes use the repository pull-request workflow rather than direct main
  mutation.
- [Required CI passes before merge](required-ci-before-merge.md) - AXM changes
  pass the repository's required deterministic checks before merge.
- [Human maintainers approve changes](human-maintainer-approval.md) - AXM
  changes receive authoritative human maintainer approval before merge.
- [Pre-launch contract changes remain coherent](pre-launch-contract-changes-remain-coherent.md) -
  Pre-launch contract changes establish one current contract without
  compatibility-only paths.
