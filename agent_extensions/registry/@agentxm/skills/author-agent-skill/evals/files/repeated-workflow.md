# Synthetic observation

In four public-library releases, maintainers copied a changelog section, removed
issue IDs, normalized headings to `Added`, `Changed`, and `Fixed`, preserved code
spans, and wrote `release-notes.md`. Errors recur when prose is paraphrased or an
unknown heading is silently dropped. The desired workflow is local and
read-only except for the explicitly named output file. Deployment and publishing
remain separate jobs.
