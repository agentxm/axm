# AXM Evaluations

Navigation for governed Evaluation Protocols and repository-native evaluation
evidence. This index owns no durable assessment claim, coverage policy, current
result, or assurance conclusion.

## Governed context

- [AXM system assurance](/assurance.md) - The confidence, evidence authorities,
  review route, and reassessment triggers for AXM changes.
- [System Requirements](/system/requirements/) - Canonical obligations whose
  satisfaction may be evaluated.
- [AXM architecture](/architecture/) - Governed Architecture authorities whose
  realization may be evaluated.

## Governed Protocols

- [Evaluation Protocols](protocols/) - Active assessment contracts organized
  by Requirement-satisfaction and Architecture-realization roles.

## Repository-native evidence

- [CI workflow](https://github.com/agentxm/axm/blob/main/.github/workflows/ci.yml) - Required repository checks and
  their execution topology.
- [Package tests](https://github.com/agentxm/axm/tree/main/packages) - Repository-native test and end-to-end

- [Detailed architecture](https://github.com/agentxm/axm/tree/main/docs/architecture) - Design-level testing
  strategies and links to exact behavior authorities.
