# Architecture documentation

A human-first pattern and strict application profile for maintaining a concise
semantic delta with required system context and conditionally admitted atomic
architecture concepts over authoritative repository and live sources.

- [Just Enough Architecture Docs](just-enough-architecture-docs.md) - A candidate human-first, risk-driven pattern for preserving accepted architecture meaning that authoritative repository and runtime sources cannot reveal reliably, without maintaining a parallel prose specification.
