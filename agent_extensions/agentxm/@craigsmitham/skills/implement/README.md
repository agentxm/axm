# Implement

Accepts an exact persisted Ready plan, separately verifies bounded repository
mutation authority, and executes that plan into one evidenced candidate for
fresh integrated review.

Plan acceptance does not grant mutation authority. Checkpoint review is not
final assurance, Review does not accept Implementation, and Implement never
ships its own result. The closeout uses the shared compact artifact,
persistence, Open-items, and next-action handoff.

Install it through `@craigsmitham/packs/gen-stack`; it is not standalone.
