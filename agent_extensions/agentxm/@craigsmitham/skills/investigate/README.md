# Investigate

Investigates one bounded observed condition with safe, discriminating evidence.
It separates expectation from observation, tests material competing hypotheses,
and returns a conclusion no stronger than the tested scope supports.

Investigate is a deliberate Gen Stack stage. Select `$investigate` explicitly;
ordinary debugging or diagnosis requests do not activate this workflow.

Use it for diagnosis, selective reproduction, possible defects, failures, and
cross-stack discrepancies. It does not authorize triage decisions, correction,
implementation, or release.

Install it through `@craigsmitham/packs/gen-stack`; it depends on the pack's
canonical process and investigation guidance and is not standalone.
