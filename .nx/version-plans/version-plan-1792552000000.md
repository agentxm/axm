`@agentxm/workspace-conventions` adds a staged commit gate for Git pre-commit hooks. A hook runs `node node_modules/@agentxm/workspace-conventions/bin/check-staged.mjs <checks-file>`; the gate isolates the index with lint-staged, runs the repository's ordered checks file against exactly what Git would commit, then typechecks the staged Nx projects and their consumers in a disposable worktree. Unstaged and untracked work stays out of every check and is restored on success or failure. `lint-staged` is a new peer dependency, and the gate also needs Git, Bash, pnpm and Nx in the workspace.
