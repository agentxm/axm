# System Requirements

Canonical obligations that apply across AXM's public boundary and change
process. Each Requirement is owned by the root [AXM System](/system.md).

## Constraints

- [Constraint Requirements](constraint/) - Binding limits on AXM's permitted
  dependency, information, telemetry, and toolchain boundaries.

## Functional

- [Functional Requirements](functional/) - Required behavior the AXM System
  preserves across workspace change, reconciliation, and telemetry.

## Process

- [Process Requirements](process/) - Durable obligations on how AXM is changed,
  reviewed, and assured.
