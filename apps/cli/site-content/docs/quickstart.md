# Quickstart

For the maintained installation and onboarding walkthrough, see
[Getting started](https://axm.sh/docs/getting-started). For agent-driven
installation, use [the installation instructions](https://axm.sh/install.md).

Once the executable is installed, `axm help getting-started` provides the
installed version's offline setup instructions. Public discovery, public
installation, and local authoring do not require an account. Sign in when
publishing or accessing private extensions, as `axm help basic-usage` describes.

This packaged entry links to the maintained journey rather than carrying a
second installation and authentication procedure.
