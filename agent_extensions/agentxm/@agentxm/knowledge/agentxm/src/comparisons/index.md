# Product comparisons

Focused comparisons with products that explicitly manage Agent Skills or
another AgentXM extension type.

- [Overview](overview.md) — Purpose, inclusion rule, and how to interpret the
  comparisons.
- [skills.sh](skills-sh.md) — Open Agent Skills discovery and installation
  from source repositories.
- [Tessl](tessl.md) — Package management and registry workflows for Agent
  Skills and agent context.
- [Google Cloud Agent Registry](google-cloud-agent-registry.md) — Cloud
  discovery, versioning, and governance for agents, MCP servers, and standalone
  skills.
- [AWS Agent Registry](aws-agent-registry.md) — Enterprise catalog and
  governance for agents, MCP servers, tools, and skills.
- [JFrog Agent Skills Registry](jfrog-agent-skills-registry.md) — Enterprise
  distribution, security, and governance for Agent Skills.
