# PawMatch (CocoaPods consumer app)

`pawmatch` is a tiny macOS command-line app that consumes the
`AgentXMExampleTinyFlags` pod via CocoaPods. It exists to demonstrate
**consumption** of an AXM-enabled pod — exactly the codebase the companion AXM
skills and subagent in `../swift-cocoapods-lib/.axm/extensions/` are designed to
operate on.

`pawmatch` is not publishable to Trunk — it exists to demonstrate the
CocoaPods consumer shape AXM detects.

The app also ships its own companion AXM skill,
[`swift-cocoapods-pawmatch-find-a-pet`](./.axm/extensions/@examples/skills/swift-cocoapods-pawmatch-find-a-pet/src/SKILL.md),
which guides an agent through using `pawmatch` to help an end user find and
apply for an adoptable pet. See the
[parent README](../README.md#app-extension--pawmatch) for the spec.

## Build

This example targets a developer with Xcode and CocoaPods installed:

```bash
pod install                      # generates PawMatch.xcworkspace from Podfile
open PawMatch.xcworkspace        # opens Xcode for build / run / test
```

The CocoaPods integration is the load-bearing piece of this example — `pod
install` resolves `AgentXMExampleTinyFlags` from the sibling `../swift-cocoapods-lib/`
via `:path =>` (see [`Podfile`](./Podfile)) and copies the pod sources plus
the `axm.json` sidecar into `Pods/AgentXMExampleTinyFlags/`. AXM's CocoaPods
detector reads this file to surface the companion pack as a package-author
recommendation.

> [!NOTE]
> This directory ships the `Podfile`, Swift sources, and tests. The
> `PawMatch.xcodeproj` / `PawMatch.xcworkspace` are generated by Xcode and
> `pod install` and intentionally not committed — every CocoaPods consumer
> follows this same shape (commit the Podfile + sources, generate the
> workspace locally). A developer reproducing the example creates a macOS
> "Command Line Tool" Xcode project named `PawMatch`, adds the files under
> `PawMatch/` to the target, adds the test files under `PawMatchTests/` to the
> test target, and runs `pod install`.

Run the CLI from Xcode (Product → Run with arguments) or from the built
binary:

```bash
./build/Debug/PawMatch browse
./build/Debug/PawMatch show pepper
./build/Debug/PawMatch match --has-kids --active
./build/Debug/PawMatch apply biscuit
./build/Debug/PawMatch fees
./build/Debug/PawMatch return-support
./build/Debug/PawMatch donate
./build/Debug/PawMatch donate brother-wolf --open
```

## Library dependency

The app consumes the `AgentXMExampleTinyFlags` pod via CocoaPods:

```ruby
pod 'AgentXMExampleTinyFlags', :path => '../swift-cocoapods-lib'
```

The sibling `../swift-cocoapods-lib/` is the source of that pod. In a real consumer
the dependency would be specified by version against Trunk:

```ruby
pod 'AgentXMExampleTinyFlags', '~> 0.1'
```

## Flag seams

Flag definitions live in [`PawMatch/Flags.swift`](./PawMatch/Flags.swift).
Each is wired into at least one command path so the companion skills have
realistic targets:

| Flag                            | Type    | Used in  |
| ------------------------------- | ------- | -------- |
| `home-check-followup`           | bool    | `apply`  |
| `fee-breakdown-detailed`        | bool    | `fees`   |
| `long-stay-highlight`           | bool    | `browse` |
| `suggest-donate-after-adoption` | bool    | `apply`  |
| `show-charity-ratings`          | bool    | `donate` |
| `recommendation-strategy`       | variant | `match`  |
| `match-quiz-depth`              | variant | `match`  |
| `pet-card-style`                | variant | `browse` |
| `donate-focus-default`          | variant | `donate` |

Rollouts are deterministic per user (the CLI uses the `$USER` environment
value as the session identifier), so running the same command twice produces
the same flag values.

## Domain framing

The CLI is intentionally framed as a shelter / rescue adoption center — not a
retail pet store — following mainstream animal-welfare best practices:

- "Adopt, don't shop"
- Matching over transacting (counselor-style questionnaire, see `match`)
- Hold and meet-and-greet periods are present in the `apply` flow
- Transparent adoption fees (`fees`) that itemize spay/neuter, vaccines,
  microchip
- No-judgment return support (`return-support`)
- Long-stay animals highlighted in `browse`

## Donate command

`donate` shows a curated, static list of well-known, highly-rated
animal-welfare organizations with their official donation URLs. The CLI never
processes payments. Every output includes a disclaimer to verify ratings
independently before giving. See [`Charities.swift`](./PawMatch/Charities.swift).

## Tests

Tests are XCTest cases in [`PawMatchTests/`](./PawMatchTests/) and cover every
command's happy path plus the unknown-command, unknown-pet, and
unknown-charity error paths. Run them from Xcode (`Cmd+U`) or with:

```bash
xcodebuild test -workspace PawMatch.xcworkspace -scheme PawMatch
```

The `xcworkspace` referenced above is the one CocoaPods generates from the
`Podfile`.
