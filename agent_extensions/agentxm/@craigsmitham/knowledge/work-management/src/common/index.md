# Common work-item guidance

Shared contracts and guides that apply across Operational Incident Records,
Defect Reports, and Changes. Select only the concern needed for the current
operation.

- [Work-item content contract](work-item-content-contract.md) - Defines the
  common semantic slots, their conditional applicability, and the composition
  order for portable work-item templates.
- [Preserving evidence and provenance](preserving-evidence-and-provenance.md) -
  Use when creating or substantively revising a work item so sources,
  uncertainty, attribution, and decision authority survive synthesis.
- [Preserving technical context](preserving-technical-context.md) - Use when
  supplied findings, constraints, designs, implementation ideas, test strategy,
  or tradeoffs must survive transfer into a work item.
- [Maintaining work-item identity and relationships](maintaining-identity-and-relationships.md) -
  Use when creating, relating, duplicating, merging, splitting, superseding, or
  reopening work items without losing independently meaningful history.
- [Managing work-item lifecycle and completion](managing-lifecycle-and-completion.md) -
  Use when changing disposition, delivery, verification, operational, or
  closure state while keeping those dimensions independent.
- [Defining work-item verification](defining-verification.md) - Use when a work
  item needs observable completion conditions, an evidence strategy, or a
  bounded verification result.
- [Mapping work items to native hosts](mapping-to-work-item-hosts.md) - Use when
  representing work-item meaning in tracker fields, labels, relationships, and
  body content without duplicate authority.
- [Applying repository-specific work-item considerations](applying-project-specific-considerations.md) -
  Use when repository instructions add security, compatibility, data,
  accessibility, operational, or other content obligations to a portable work
  item.
- [Titling and summarizing work items](titling-and-summarizing-work-items.md) -
  Use when a work item must be recognizable in lists and search without
  changing its underlying body meaning.
