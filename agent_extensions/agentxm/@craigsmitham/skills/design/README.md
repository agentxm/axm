# Design

Produces one proportional Change Design. `$design` accepts only an exact
persisted Ready Specification, then persists the first coherent Design Draft
and later state changes in place.

Design compares alternatives only when a real consequential choice exists. It
owns technical and Evaluation realization, not desired-state ratification,
planning, implementation authority, or release. Its portable form leads with
Summary, Open items, bindings, and Specification reconciliation, then uses
narrow comparisons and realization mappings.

Install it through `@craigsmitham/packs/gen-stack`; it is not standalone.
