# Author architecture docs

Creates and revises small software architecture corpora that preserve accepted,
durable functional, quality, and structural meaning while linking precise and
current facts to their executable owners.

Use it for architecture overviews, responsibility and boundary documents,
cross-cutting architectural concerns, corpus migrations, and focused document
reviews. Do not use it to choose among architecture alternatives, turn a
proposal into accepted design, mirror the implementation in prose, or audit an
entire documentation corpus.

This skill is a non-standalone member of the software-engineering pack because
it loads that pack's architecture knowledge.

## Install

```bash
axm install @craigsmitham/packs/software-engineering
```

## Example

> Revise `docs/architecture/reservations.md` so it preserves the accepted
> reservation responsibility, recovery invariant, and evidence routes without
> duplicating the state-machine tests.
