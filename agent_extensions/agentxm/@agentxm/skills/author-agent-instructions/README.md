# Author Agent Instructions

Create or revise `AGENTS.md`, `CLAUDE.md`, and related scoped repository
instruction systems. The workflow resolves the active harness contract and
canonical sources, keeps persistent guidance at the smallest truthful scope,
routes deeper content to its proper owner, reconciles projections, and validates
representative and adjacent entry points.

Use it for creating, fixing, trimming, restructuring, reindexing, localizing,
or remediating agent instructions. Use `audit-agent-instructions` for a
separate conformity assessment or closure verification. A same-agent closure
pass is verification, not independent approval.

When AXM manages the instruction system, the workflow uses AXM's instruction
inventory, lint, and previewed reconciliation rather than editing aliases or
managed regions directly.

## Install

```sh
axm install @agentxm/packs/agent-engineering
```

## Example

> Revise our repository instructions to remove parent-child duplication,
> preserve useful discovery routes, and verify the effective context from the
> root and package working directories.
