# Local Markdown Formatter

This is a complete synthetic AXM skill package. The package root contains the
registry manifest, human documentation, provenance, and license. The portable
Agent Skills artifact root is `src/`; AXM installs that directory as the named
skill directory, so `src/SKILL.md` becomes the portable root entry point and
`src/scripts/format.mjs` remains its relative helper.

The intended cohort is pinned, local-only internal use. No host compatibility,
publisher-signature verification, behavioral evidence, release approval, or
public-distribution claim is implied by this fixture.
