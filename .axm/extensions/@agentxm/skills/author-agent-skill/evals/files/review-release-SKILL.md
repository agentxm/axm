# Review a release

Review supplied Markdown release notes and report missing sections, malformed
headings, or incomplete entries. Do not edit, deploy, publish, tag, or create a
release.

## Workflow

1. Read the supplied release notes.
2. Check the heading and bullet structure.
3. Return findings with exact source locations.

Finish when every finding cites an observable part of the supplied notes.
