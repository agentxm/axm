# Context

The informational environment an agent receives, discovers, produces, and
carries through work.

- [Context engineering](context-engineering.md) - How the informational
  environment is selected, structured, routed, used, refreshed, and retired.
- [Context forms and lifecycles](context-forms-and-lifecycles.md) - Why
  persistent guidance, task state, knowledge, observations, feedback, and
  memory require different owners and retention.
- [Context quality and authority](context-quality-and-authority.md) - How
  relevance, scope, currency, provenance, trust, and cost govern selection.
- [Progressive disclosure](progressive-disclosure.md) - Compact routes,
  meaningful selection conditions, and on-demand depth that conserve attention.
- [Memory, compaction, feedback, and continuity](memory-compaction-and-continuity.md) -
  How working state survives long tasks without turning history into authority.
- [Context gardening](context-gardening.md) - How observed work drives
  authority repair, routing, pruning, promotion, and retirement.

For persistent scoped guidance such as AGENTS.md and CLAUDE.md, see
[agent instruction files](../domains/software-engineering/agent-instruction-files.md). For measuring
