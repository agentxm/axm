# Work management

Portable concepts, guides, and templates for consistent software work items.
Use this bundle to classify, author, relate, maintain, and verify Operational
Incident Records, Defect Reports, and Changes without adopting a particular
tracker, delivery method, requirements system, or architecture framework.

## Foundations

- [Software work-item taxonomy](software-work-item-taxonomy.md) - Defines the
  portable work-item roles, classifications, neighboring activities, and
  distinctions that every guide and template in this bundle applies.
- [Common work-item guidance](common/) - Shared content, evidence, identity,
  lifecycle, verification, tracker-mapping, local-policy, technical-context,
  and brief-authoring guidance.

## Work-item roles

- [Defect Reports](defects/) - Concepts, authoring, triage, corrective-change
  relationships, and a portable template for observations that may indicate a
  defect.
- [Changes](changes/) - Concepts, classification, authoring, and a portable
  template for bounded proposed or authorized software modifications.
- [Operational Incident Records](incidents/) - Concepts, live-record guidance,
  and a portable template for coordinating current or imminent operational
  impact.
